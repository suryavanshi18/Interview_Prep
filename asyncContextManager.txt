lifespan events
Code that must be executed before application starts up and right after application shuts down
after handling many requests
hence called lifespan
suppose you have ml model for your fastapi
It should serve all the request


load the model before requests are handled but only when before application starts receiving requests
not when code is loaded


from contextlib import asynccontextmanager
from fastapi import FastAPI


def fake_answer_to_everything_ml_model(x: float):
    return x * 42


ml_models = {}
@asynccontextmanager
async def lifespan(app: FastAPI):
    # Load the ML model
    ml_models["answer_to_everything"] = fake_answer_to_everything_ml_model
    yield
    # Clean up the ML models and release the resources
    ml_models.clear()


app = FastAPI(lifespan=lifespan)


@app.get("/predict")
async def predict(x: float):
    result = ml_models["answer_to_everything"](x)
    return {"result": result}


part before yield executes before application starts
after yield will be executed after application has finished

| Concept             | Meaning                 |
| ------------------- | ----------------------- |
| `async`             | function can pause      |
| `await`             | pause here, don’t block |
| `httpx.AsyncClient` | async HTTP requests     |
